TRANSPARENCY

Know what you’re looking at.

Candidate names and counts come from BERNAMA’s PRN Melaka 2026 results portal. Official and unofficial feeds are kept separate. “—” means unreported, never zero. Percentages are shares of reported candidate votes, not voter turnout.

Update policy

The browser checks the published snapshot every 60 seconds. The included GitHub workflow checks BERNAMA about every 5 minutes once installed and enabled; GitHub can delay runs. Source changes and outages retain the last valid snapshot and display a warning.

News or Facebook claims are not automatically treated as election results. No Facebook feed is connected. Cross-check claims against the results feed before using them.
