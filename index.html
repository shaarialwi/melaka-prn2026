Know what you’re looking at.

Choose BERNAMA, Astro AWANI or SPR to view its own candidate names and counts. Sources are kept separate and are never added together. Astro AWANI counts remain unofficial unless that source marks a seat official. SPR is the official election authority. “—” means unreported, never zero. Percentages are shares of reported candidate votes, not voter turnout.

Update policy

The browser checks the published snapshot every 60 seconds. The GitHub workflow checks BERNAMA, Astro AWANI and SPR about every 5 minutes; GitHub can delay runs. Source changes and outages retain the last valid snapshot and display a warning.

News or Facebook claims are not automatically treated as election results. No Facebook feed is connected. Cross-check claims against the results feed before using them.
